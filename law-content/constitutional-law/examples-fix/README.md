# 宪法学「生活例子」修订候选（4 条）
仅候选，未改动 law-study/courses/constitutional-law/content.json；上线请由开发侧按小节 id 替换 `body` 中"生活例子："行。人物一律仅用甲乙；未新增任何案号、判决、统计数据或他人观点。

| 小节 | 原句 | 新句 | 理由 | 法源核验 |
|---|---|---|---|---|
| ch1-s1 | 甲问借款期限，乙应提示不能只看宪法。 | 甲以为宪法不管身边事，乙应指出公民基本权利由宪法规定。 | 借款期限属民法场景，跑题；改为紧扣宪法作为根本法规定公民基本权利的定位 | 已核验（北大法宝）《宪法》(2018修正)第33条等，现行有效 |
| ch6-s1 | 甲说乙书包必须归国家，丙应指出分类错误。 | 甲说私营店铺也须全部国有，乙应指出多种所有制共同发展。 | 书包是生活资料且与6.3财产权重叠，并违反仅用甲乙约束；改为公有制为主体、多种所有制共同发展的所有制场景 | 已核验（北大法宝）《宪法》(2018修正)第6条、第15条，现行有效 |
| ch7-s3 | 甲强迫乙参加宗教活动，丙应指出自由包含不受强迫。 | 甲强迫乙信教，乙应知自由包含不受强制和不得歧视。 | 删除丙，改为仅用甲乙；要点仍为不得强制信教或不信教、不得歧视 | 已核验（北大法宝）《宪法》(2018修正)第36条，现行有效 |
| ch7-s5 | 甲称任意单位能以方便为由查乙通信，丙应否定。 | 甲称单位能以方便为由查乙通信，乙应知检查须法定机关和程序。 | 删除丙，改为仅用甲乙；要点仍为通信检查限于法定目的、法定机关与法定程序 | 已核验（北大法宝）《宪法》(2018修正)第40条，现行有效 |

句式均为"一句误认 + 一句纠正"，纠正句以乙应…收尾；四条均未改写任何法律要点。
